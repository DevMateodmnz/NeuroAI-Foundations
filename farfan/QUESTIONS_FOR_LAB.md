# Questions for a computational-neuroscience laboratory conversation

These are prompts for understanding, not flashcards. Before asking a researcher, prepare a concrete example, relevant equation or data type, and an honest statement of what remains unclear.

| Question | What a substantive answer must address | Concepts to study first |
| --- | --- | --- |
| What constitutes a neural code? | A mapping between a defined stimulus/task variable and a defined neural response, under noise and a time scale; multiple codes may coexist. | Random variables, stimuli/responses, experimental design. |
| Rate code versus temporal code? | What response statistic is retained (count/rate, latency, intervals, patterns), what information it preserves, and how to compare estimators fairly. | Spike trains, bins, ISIs, entropy. |
| How do we know a neuron carries information about a stimulus? | Association/predictability, controls for confounds and behavior, uncertainty, and why decoding alone does not prove use or causality. | Encoding/decoding, controls, causal inference. |
| What does “information” mean mathematically? | Entropy, conditional entropy, mutual information, units (bits), sampling bias, and limits of interpretation. | Probability, logarithms, estimation. |
| How is stimulus information measured experimentally? | Sensor calibration, stimulus timing, trial identity, behavioral state, neural measurement, and synchronization. | Instrumentation, metadata, time bases. |
| What is lost between receptor, peripheral nerve, and cortex? | Transformations, convergence/divergence, noise, feedback, different code formats, and measurement limitations. | Sensory pathways, populations, systems neuroscience. |
| Why use the vibrissal system as a model? | Experimental accessibility, rich active-sensing behavior, measurable mechanics, and its limits for human generalization. | Somatosensation, animal-model validity. |
| What is biomimetic computation? | A biological observation abstracted into a testable engineering principle with a real baseline; not superficial resemblance. | Modeling, ablation/baseline design. |
| When is a biological mechanism technologically useful? | A specific performance, robustness, energy, data-efficiency, or control advantage under a defined task and cost. | Evaluation design, systems constraints. |
| What makes a computational-neuroscience model scientifically useful? | Clear assumptions, link to data, predictions that could fail, parameter identifiability, and explanatory scope. | Differential equations, model comparison, falsifiability. |
| What is the smallest useful task for a junior computational collaborator? | Current data format, reproducibility gap, analysis objective, supervision boundary, and expected deliverable. | Git, Python, data contracts, research ethics. |

## Questions to ask about joining the learning environment

- Is *Introducción a la Neurociencia Computacional* expected to run again, and what mathematical/programming prerequisites does it assume?
- Does FACET permit participation or enrollment through the `alumno vocacional` route for this situation? Which office determines that?
- Which of the reading-list papers best reflects the group’s current methods and questions?
- Is there a bounded, supervised data/reproducibility/visualization task where a software-oriented learner could help without overstepping scientific judgment?

Do not ask for a position by claiming mastery. Bring the EEG audit, this repository’s small first module, and specific questions about methods.
